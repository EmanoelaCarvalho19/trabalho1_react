# 📘 trabalho1_react

Repositório desenvolvido para a realização do exercício proposto na
disciplina, com o objetivo de praticar conceitos de desenvolvimento e
versionamento utilizando **Git e GitHub**.

------------------------------------------------------------------------

# 📋 Descrição do Projeto

Este projeto foi desenvolvido com base no enunciado disponibilizado pelo
professor, com o objetivo de implementar a solução solicitada e aplicar
boas práticas de organização de código e versionamento.

O projeto contém a implementação do exercício proposto, seguindo os
critérios definidos no arquivo de enunciado.

------------------------------------------------------------------------

# 🛠 Tecnologias Utilizadas

As principais tecnologias utilizadas no projeto foram:

-   Linguagem: *(JavaScript / Css)*
-   IDE/Editor: Visual Studio Code
-   Controle de versão: Git
-   Repositório remoto: GitHub

# ▶️ Como Executar o Projeto

1.  Clone o repositório

```{=html}
<!-- -->
```
    git clone https://github.com/emanoelsp/exercicio1902.git

2.  Acesse a pasta do projeto

```{=html}
<!-- -->
```
    cd exercicio1902

3.  Abra o projeto na sua IDE de preferência

Exemplo com VS Code:

    code .

4.  Execute o arquivo principal do projeto.

*(backend = npm start, frontend = npm run dev.
